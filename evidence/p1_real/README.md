# Frozen P1 real Go2 evidence

This directory is the self-contained evidence bundle consumed by
`calibagent-audit`. It was generated by source commit
`100fe68378a7966d0fb6b0d686cf9a247c604f19` from the immutable source archive
whose SHA-256 is
`273d3f5f367cccb9002edb26e5256c8b6a9de5b08b36913613595805b12b978b`.

The bundle contains the copied final raw table, canonical observations,
leave-one-session-out aggregate and fold metrics, delivery-native trace
verification, half-rate sampling sensitivity, the frozen capture plan, and the
original delivery archive. Artifact hashes are frozen in
`reports/artifact_checksums.sha256`.

Run from the repository root:

```bash
calibagent-audit --workspace . --require-ready
```

Known limitations are recorded verbatim in `manifest.json` and
`delivery_verification.json`; they are summarized in
`reports/p1_real_report.md`.

The other minimal, versioned inputs consumed by the same clean-clone audit are
stored in sibling directories `evidence/p1_baseline/`, `evidence/p1_capture/`
and `evidence/p3_main/`.
