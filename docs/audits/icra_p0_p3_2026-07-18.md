# ICRA-level P0-P3 audit — 2026-07-18

## Verdict

NO_GO. The repository is a tested P0-P3 research prototype, not a
publication-ready evidence package.

## Completion-correction record

The previous completion claim conflated three different facts:

1. named deliverables existed;
2. component tests passed;
3. phase and publication claims were scientifically established.

Only the first two were true. The audit reused the repository's own requirement
matrix as proof, so producer claims and verifier evidence were not independent.
It also treated artifact checksums and software coverage as substitutes for
experimental validity. The result was a self-confirming completion loop.

## Blocking findings

- P3 pooled `(family, seed)` observations that share latent parameters. With
  seed as the independent unit, Active vs LHS gives `p=0.09375`, not a
  significant primary result.
- The replay backend emits two samples, which the common measurement pipeline
  rejects. The reported P1 baseline bypasses that vertical slice.
- The workspace and both manifests are unversioned.
- There is no real Go2 dense-data manifest and no committed generator for the
  frozen P1 synthetic dataset.
- Synthetic observation covariance and configured model noise are both charged
  for the same generated noise, so the P2 calibration interpretation is
  ambiguous.
- Main-seed count, D-opt, dense-oracle, without-task-weight, and 30% effect-size
  gates are missing or failed.
